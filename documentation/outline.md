The 7 planned core functionalities

1. The Read Evaluate Print Loop. This is the core of a shell. Requires a barebones C while loop which calls the parser. The parser uses the lexical analyzer to determine which input is valid and then parses the user input.

2. Builtins. Core builtins are Print Working Directory (pwd). Change Directory cd(). Exit(). Help().

3. Fork Execute Wait. This allows us to run programs within the shell and enables future functionality and command line inputs not defined in the builtins.

4. Piping. This allows us to pipe the output of commands into the next command is extremely useful for the next feature.

5. File Redirection. My implementation of this was rushed and not as complete as I would have liked but the basics are present. Allows the user to redirect output or input.

6. Signal Handling. Async handling of signals (think CTRL + C to kill a program in a CLI). This allows us to use three basic signals on child processes to kill them without killing the shell itself.

7. AI functionality. There are three extra builtins which are tied a locally ran LLM called Ollama which are as follows. "fix" which looks at the previously entered command and gives a description on how to fix it if invalid, if valid ignores. "ai" which allows the user to ask the LLM for specific commands if they don't know them. "ai script" which allows the user to ask the LLM to generate a script to do somethning ex. make a script to make x number of directories. For executable functionality generated by the LLM there is a safeguard y/n option as well as a preview for the user to verify correctness.

Advanced UI & UX
GNU Readline Integration: Provides professional terminal features including Tab-completion, Up-arrow history, and persistent history across shell restarts.
Dynamic Colorful Prompt: A custom-built prompt that displays the current folder and changes the exit status indicator from Green (success) to Red (error) dynamically.
Variable Expansion: Supports expansion of environment variables ($USER, $HOME) and the exit status variable ($?).

Process & Data Management
Wildcard Expansion (Globbing): Automatically expands * and ? into multiple file arguments using the <glob.h> system library.
Background Execution (&): Allows commands to run in the background. Implements a SIGCHLD signal handler for asynchronous process reaping (preventing zombie processes).

Core Architecture
Reentrant Parser: Built using Flex and Bison. Unlike standard parsers, this reentrant design allows for safer memory management and better isolation between command executions.
