# Patrick-Swedenborg-Capstone
This project entails a Linux shell written in C.

DISCLAIMER: This project involved extensive usage of AI, whether it be for adding functionality or debugging.

documentation Directory:
There are three separate entities. An overview, outline, and a c file containing a prototype which is the same shell we made in Operating Systems Programming but showcases the idea and inspiration behind this project.
The overview goes over the goal of the project and technologies used. The outline covers most of the functionality.

src Directory:
This is the source code directory, there are a lot of extra files generated by flex and bison but are necessary, the three primary source files are scanner.l which is the lexical analyzer, parser.y which is the parser, and logic.c which contains all of the functionality.

Working on learning how to use Flex and Bison to build a more robust REPL for the shell. At the moment the shell has not been started until I learn how to use these tools.

3/22/2026 Milestone 2 Progress
Progress on the REPL has been slow and unexpectedly difficult, however after an entire day of deep diving on the internet I have made a massive breakthrough and am now in a position to finish it up. Current progress is a functioning lexical analyzer and parser which are linked to a seperate C file which will handle most of the logic to maintain readibility. As of right now the parser is able to parse for any arbitrary number of arguments entered on the command line and stores them in an array. Current issue is that the parser can only run once so in order to get the main loop of the shell working I will have to refactor the lexical analyzer and parser to allow the parser to be "reentrant". I did attempt to flush the input buffer and restart the lexical analyzer but that simply isn't a working solution. Lastly I did some research on how to utilize an LLM in the shell and will be using a free LLM called Ollama which runs locally and will be enough for what I am looking to do.

Last feature will be AI integration for the user to ask AI to execute commands or run scripts etc. This is the feature I will be spending the most amount of the remaining time on in hopes I can get it functional.

Installation and Setup (BASH)
1. Dependencies
   sudo apt-get install libreadline-dev flex bison

2. Ollama (For AI features)
   curl -fsSL https://ollama.com | sh
   ollama pull qwen2.5-coder:3b

3. git clone https://github.com/CIDS-484-Spring-2026/Patrick-Swedenborg-Capstone.git

4. In the /src folder use the makefile by typing make then enter

5. If everything up to here worked properly, use the command ./shell to run the shell

6. NOTE: Only way to exit the shell is via the command exit, exiting the window, or discovering a bug!
